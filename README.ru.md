# Doorquest

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/stezkoy/flarum-doorquest.svg)](https://packagist.org/packages/stezkoy/flarum-doorquest) [![Total Downloads](https://img.shields.io/packagist/dt/stezkoy/flarum-doorquest.svg)](https://packagist.org/packages/stezkoy/flarum-doorquest)

Расширение для Flarum, которое защищает регистрацию с помощью вопросов и ответов. Новый пользователь должен правильно ответить на вопрос, чтобы зарегистрироваться — простая альтернатива (или дополнение) к приглашениям, капчам и другим барьерам при входе.

[English version](README.md)

## Возможности

### Q&A-барьер при регистрации
Когда кто-то регистрируется, форум задаёт случайный вопрос из вашего банка. Вход разрешён только после правильного ответа — отпугивает ботов и нежелательные регистрации, оставаясь дружелюбным к реальным пользователям.

### Банк вопросов
Управляйте любым количеством вопросов в админке. Каждый вопрос независим, а система выдаёт один из них случайным образом при каждой попытке регистрации.

### Регистронезависимые ответы
Ответы сравниваются без учёта регистра, поэтому `Manjaro`, `manjaro` и `MANJARO` пройдут — не нужно угадывать точное написание с больших букв.

### Опциональный лимит использований
Задайте **максимум использований** для вопроса. По достижении лимита вопрос автоматически исчезает из банка — можно ротировать вопросы после заданного числа успешных регистраций. Оставьте `0` для безлимитного.

### Автоактивация
Решите, включает ли правильный ответ немедленную активацию нового аккаунта, или вы всё ещё одобряете его вручную.

### Назначение группы
Опционально назначайте новым зарегистрированным пользователям группу, например «проверенные» или «подтверждённые» участники.

## Установка

```bash
composer require stezkoy/flarum-doorquest
php flarum cache:clear
```

## Требования

- Flarum 2.0
- PHP 8.3+

## Настройка

Откройте **Админ → Расширения → Doorquest**, затем добавьте свои вопросы во вкладке **Вопросы**. Для каждого вопроса укажите текст, ожидаемый ответ, опциональный лимит использований, автоактивацию и, при желании, группу.

## Как это работает

1. Пользователь пытается зарегистрироваться и получает случайный вопрос.
2. Он отправляет ответ вместе с id вопроса.
3. Если ответ верный, регистрация продолжается (а счётчик использований вопроса увеличивается); иначе — отклоняется.
4. Если у вопроса достигнут лимит использований, он больше не предлагается.
